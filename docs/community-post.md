Hi all,

**Widgetkeeper** is extra dashboard widgets for Homey Pro, made to sit naturally next to Homey's own with the same look and feel. Use them on Homey's dashboards, or on web dashboards you build yourself and open in any browser: a wall tablet, an old iPad, a computer or a TV.

> :white_check_mark: **Live version (1.1.2):** https://homey.app/a/com.thomassidor.widgetkeeper/
>
> :test_tube: **Test version (1.2.0)**, with the next version's widgets: https://homey.app/a/com.thomassidor.widgetkeeper/test/

## The widgets

Tap a widget for what it does and its settings. Every widget follows Homey's light and dark mode and speaks all 13 of Homey's languages.

## :desktop_computer: Web dashboards

Build dashboards of your widgets on a page served by your Homey, and open them in any browser, at home or away. Turn them on under **Apps → Widgetkeeper → Configure**. More on GitHub: https://github.com/thomassidor/widgetkeeper#web-dashboards

## :key: API key

A few widgets need a Homey API key to change things Homey doesn't let apps change on their own: Flow Buttons, Variables, Variable Presets, the Smart Stack, Media's buttons, the Keypad's Flows and the Moods. Which permissions to tick: https://github.com/thomassidor/widgetkeeper#api-key

## :speech_balloon: Feedback wanted

* **Does it look like Homey?** Spacing, fonts or colours that look off next to Homey's own widgets.
* **Your devices.** One that doesn't show up or behaves oddly: tell me the brand and model.
* **Translations.** Wording that sounds wrong in your language.
* **What's missing.** A widget you'd like to see next.

If something doesn't work, **Apps → Widgetkeeper → Configure** has a diagnostics report you can paste here (without passwords, API keys or camera addresses). Source and issues: https://github.com/thomassidor/widgetkeeper

I hope you find this useful :slight_smile:
